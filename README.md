# Coffee Shop

A Go-based project inspired by [go-coffeeshop](https://github.com/thangchung/go-coffeeshop).

This project is **not an exact copy** of the original. It includes some updates, modifications, and improvements to the project structure, tools, and implementation for learning and practical purposes.

## Reference

- [thangchung/go-coffeeshop](https://github.com/thangchung/go-coffeeshop)

## Tools & Libraries

- **Go** — Main programming language
- **Wire** — Dependency Injection
- **golang-migrate** — Database migrations
- **Buf** — Protobuf management and code generation

## Run with Nomad

### Requirements

- Docker
- Docker Compose
- Nomad
- Consul
- Vault
- jq
- curl

### Start

```bash
make dev-nomad
```

This project is mainly created for learning, experimentation, and building a reusable reference architecture for future Go projects.
